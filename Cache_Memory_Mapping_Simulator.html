6. Theory to explain in your viva

Cache hit

A hit occurs when the requested memory block is already present in cache. The CPU can access the cached data quickly.

Cache miss

A miss occurs when the requested block is not in cache. The block must be brought from main memory.

Mapping rules

  • Direct: line = block number mod number of cache lines.
  • Fully associative: the block can occupy any cache line.
  • 2-way set associative: set = block number mod number of sets; the block can occupy either way in that set.

Replacement policy: this model uses FIFO within a set / fully associative cache when a replacement is required. Direct mapping always replaces the block in its assigned line.
